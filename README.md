# Portfólio — Lucas de Souza Almeida

Portfólio de **Lucas Almeida**, graduando em Engenharia de Software na Universidade Federal do Ceará (UFC · Campus Russas) e Técnico em Informática pelo Instituto Federal do Maranhão (IFMA).

Apresenta projetos em inteligência artificial, engenharia de software e desenvolvimento web com validação experimental, código aberto e métricas comprovadas.

---

## 🚀 Projetos em Destaque

- **[Federated-XAI-Lab](https://github.com/Lucas-715/Federated-XAI-Lab)**: Framework experimental que avalia convergência e explicabilidade (Integrated Gradients) com 6 clientes simulados no dataset UCI HAR (`Macro-F1 0,9270 ± 0,0089 · 5 sementes · 9 voluntários não vistos`).
- **[Gambit-Lab](https://github.com/Lucas-715/Gambit-Lab)**: Game-driven multi-agent framework para debate e auditoria baseados em evidências utilizando LLMs, Xadrez, Go e raciocínio rastreável com motores determinísticos (`python-chess`, `GoEngine`).
- **[GameHunter](https://github.com/Lucas-715/GAMEHunter)**: Plataforma para catalogação e comparação de preços de jogos para PC com Next.js, TypeScript, Prisma ORM e NextAuth.

## ⚡ Arsenal Tecnológico

- **Frontend & UI**: React 18, TypeScript, Tailwind CSS, Lucide React, Canvas API
- **Tooling & Build**: Vite, PostCSS, ESLint

## 🛠️ Como Executar Localmente

```bash
# 1. Clonar o repositório
git clone https://github.com/Lucas-715/Portifolio.git
cd Portifolio

# 2. Instalar dependências
npm install

# 3. Iniciar servidor de desenvolvimento
npm run dev

# 4. Gerar build de produção
npm run build
```
